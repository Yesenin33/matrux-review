## Конспект

- Программа: `#include <iostream>`, `int main()`, `std::cout << ... << '\n'`; `return 0`.
- Типы: `int`, `double`, `char`, `bool`, `auto`; целочисленное деление `7 / 2 == 3`, `7 % 2 == 1`; `7 / 2.0 == 3.5`; при выводе `std::cout << 3.5` печатает `3.5`, `std::cout << 2.0` печатает `2`.
- `bool` в `cout` печатается как `1`/`0` (без `std::boolalpha`).
- Управление: `if/else`, тернарный `?:`, `switch` (без `break` — проваливание), `for`, `while`, `do-while`, цикл по диапазону `for (int x : v)`.
- Функции: объявление и определение; передача по значению копирует, по ссылке `int&` меняет оригинал, `const T&` — без копии и без изменений; перегрузка.
- Ссылки и указатели: ссылка — другое имя объекта, нельзя перепривязать; указатель хранит адрес `&x`, разыменование `*p`; `nullptr`.
- Память: `new`/`delete`, `new[]`/`delete[]`; утечка — память без `delete`; `std::unique_ptr`, `std::make_unique` освобождают сами (RAII).
- Строки и векторы: `std::string` (`size()`, `+`, `substr(pos, len)`, `find`); `std::vector<int>` (`push_back`, `size()`, `[]`, `at()` с проверкой границ).
- Классы: поля и методы, `public`/`private`, конструктор со списком инициализации, деструктор вызывается при выходе из области видимости — в обратном порядке создания.
- Стандартная библиотека: `<algorithm>` — `std::sort`, `std::count`, `std::find`, `std::max_element`; `<numeric>` — `std::accumulate`; `std::map` хранит ключи упорядоченно.

## Почему без компиляции

Компилятора в образах нет. Задачи «что напечатает» составлены так, чтобы вывод был однозначным по стандарту (без неопределённого поведения), и сверены вручную по правилам выше.

1. Начало (открыт): первая программа · типы и выражения.
2. Управление: ветвления · циклы.
3. Функции: параметры и перегрузка.
4. Ссылки и указатели: ссылки · указатели.
5. Память: динамическая память и умные указатели.
