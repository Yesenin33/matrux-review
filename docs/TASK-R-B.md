# TASK-R-B — главная: два подраздела вместо витрины

Проект: `/root/palma`. Задача выполняется после `TASK-R-A.md`. Модель: claude-opus-5-5.

## Что есть сейчас

`app/src/main/java/ru/palma/app/ui/screens/HomeScreen.kt` — витрина: блоки `REVOKED`, `BUY`, `STATUS`, `TERMS`, `INSIDE`, `LOCKED` из `homeBlocks(ui)` (`app/src/main/java/ru/palma/app/ui/state/`, файл со `HomeUi`/`HomeBlock`).

## Что требуется

Главная — это только два подраздела. Всё текущее содержимое (кнопка покупки, строка статуса подписки, выбор тарифа, «Что внутри», логотипы систем, карточка курсов, строки фич, строка «Что откроется в Pro», блок «Нет доступа») с главной убрать.

### Подраздел 1 — «Базовые знания»

Свободный, без замка. Пункты строго в этом порядке, каждый открывает существующий экран шпаргалки (`Route.SECTION`, `SectionScreen`):

1. `start` — Первые шаги
2. `linux` — Команды Linux
3. `terms` — База ПК

Заголовок раздела — новая строка `home_basics` = «Базовые знания». Заголовки пунктов брать из json шпаргалок (`title` в `app/src/main/assets/sheets/<id>.json`), не хардкодить.

### Подраздел 2 — «Команды и расширенные базовые знания»

Пункты, в этом порядке: `files`, `git`, `hardware`, `packages`, `users`, `services`, `network`, `disks`, `logs`, `scripts`, `languages`.

- у пользователя есть Pro — раздел открывается, пункты открывают шпаргалки как в первом разделе;
- Pro нет — раздел целиком под замком: в заголовке/строке иконка замка (`Lucide.Lock`), пункты не раскрываются, нажатие на раздел открывает экран подписки (`Route.SUBSCRIPTION`).
- никаких текстовых подсказок, никаких «Купите Pro, чтобы…» — только замок и переход на подписку.

Заголовок раздела — новая строка `home_advanced` = «Команды и расширенные базовые знания».

### Реализация

- Список разделов и порядок пунктов — в Kotlin как данные (например `homeSections` в ui/state), без русских строк: id шпаргалок латиницей, названия из `strings.xml` и json.
- Иконки пунктов — существующая `sectionIcon(id)` из `KnowledgeScreen.kt`.
- Разметку карточек делать существующими компонентами (`Card`, `Tappable`, `LucideIcon`, `Palma.type/space/colors`), без новых стилей и без самодельных теней/градиентов.
- `HomeScreen.kt` после правки не должен содержать мёртвых composable и импортов; `HomeActions` получает `onSection: (SectionRow) -> Unit` и `onSubscribe: () -> Unit`.
- `MainActivity.kt`: `Route.HOME` передаёт в `HomeScreen` список шпаргалок (`graph.courseLibrary.sheets`) и `paid`; нажатие пункта — существующий `openSection`-путь (`sectionId` + `Route.SECTION`), нажатие запертого раздела — `Route.SUBSCRIPTION` без промежуточных окон.
- Ключи `home_buy`, `home_inside`, `home_feature_*`, `home_locked`, `home_sheets`, `home_courses`, `locked_*`, плюралы `home_systems` — удалить из `strings.xml`, если после правки не используются. `home_revoked_*`/`home_reregister` удалять только если `REVOKED`-блок больше нигде не показывается (учти: доступ может отзываться сервером — если блок нужен, оставь экран с этим состоянием, но не на главной, а там, где он уместен; в отчёте объясни решение).
