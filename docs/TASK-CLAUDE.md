# Задача: аудит производительности и корректности Matrux

Проект: /root/palma — Android-приложение (Kotlin + Jetpack Compose), которое запускает Linux-дистрибутив
внутри proot на телефоне и показывает его рабочий стол по VNC. Бэкенд каталога образов — FastAPI в backend/.

## Что нужно

Только анализ. **Код не менять, файлы не создавать, кроме одного отчёта** `/root/palma/docs/AUDIT.md`.

Разобрать по файлам:

1. `app/src/main/java/ru/palma/app/shell/VncClient.kt` — клиент RFB. Смотреть: переиспользование буферов,
   лишние аллокации на кадр, разбор encodings (Raw, CopyRect, DesktopSize, Tight), обработку неполных чтений,
   потокобезопасность, утечки Bitmap.
2. `app/src/main/java/ru/palma/app/session/SessionController.kt` — жизненный цикл сессии, `syncGeometry()`,
   гонки между `frames`, `requestGeometry()` и пересборкой стола, кулдауны.
3. `app/src/main/java/ru/palma/app/ui/screens/DesktopScreen.kt` — рендер кадра: `asImageBitmap()` на каждый кадр,
   рекомпозиции, `frameStamp`, ввод (мышь/тач/клавиатура).
4. `image-build/palma-session` — shell-супервизор гостя: запуск Xvnc/Xvfb, x11vnc, перезапуски, обработка
   поворота (`geometry-request`), чистка.

## Формат отчёта

`docs/AUDIT.md`, по-русски, без вводных фраз. По каждому пункту: файл и строка, что не так, чем это грозит
(лаги / утечка / зависание / неверный кадр), и **конкретная правка** (что заменить на что). В конце —
список из 10 самых важных правок в порядке приоритета.

Правила проекта: никаких пояснительных комментариев в коде; размеры в десятичных МБ; приложение для RuStore,
требования Google Play не применять; интерфейс приложения — русский.
