# Palma — DESIGN.md

Закрытая система. Любой экран собирается только из этих значений.
Ссылка: Apple (oh-my-design catalog), светлая тема, без градиентов и без рамок.

## Основа

- Продукт: Palmа — рабочий Linux-десктоп на телефоне, без Docker и без root.
- Тон: спокойный, дорогой, немногословный. Интерфейс уходит, содержимое остаётся.
- Светлая тема. Тёмная — отдельная сборка, не инверсия.

## Цвета (только через токены)

```
--canvas:      #f5f5f7
--surface:     #ffffff
--surface-alt: #fafafa
--ink:         #1d1d1f
--ink-soft:    #515154
--muted:       #6e6e73
--accent:      #0071e3
--accent-press:#0062c4
--accent-tint: #eaf2fd
--success:     #1d8a4e
--warning:     #b25000
--hairline:    #d2d2d7
--danger:      #d70015
```

Правила:
- Акцент один. Он только на главном действии экрана и на ссылках. Больше нигде.
- Рамок нет. Границу даёт разница поверхностей и тень, не линия.
- Никаких градиентов, никакого стекла, никаких цветных плашек под текстом.
- Красный (`--danger`) — только для удаления и ошибок, и только словом, не заливкой.
- Дорожка полосы прогресса — `--hairline`, заполнение — `--accent`.

## Шрифт

- Гарнитура: Inter (переменная), fallback — системная. Заголовки вес 600, текст 400.
- Display: 32 / 36, tracking −0.02em
- Title: 20 / 26, tracking −0.01em
- Body: 15 / 22
- Caption: 12 / 16
- Code: 13 / 20, моноширинный `res/font/mono.ttf`, вес 500, tracking −0.01em, без лигатур (`liga 0, calt 0`): `>=` должно читаться как два символа. Только строки запуска гостя, код в уроках и командах шпаргалок.
- Clock: 84 / 84, вес 600, tracking −0.03em. Только часы окна входа поверх кадра рабочего стола.
- Максимум четыре размера на экран. Больше — уже не этот продукт.

## Сетка и форма

- Базовая единица 8. Поля страницы 20. Между блоками 24, внутри карточки 20.
- Радиусы: карточка 20, контрол 12, сегмент 8, пилюля 999. Сегмент — только внутри дорожки переключателя.
- Тень: `0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.06)`. Одна на карточку.
- Высота кнопки 56, минимальная зона нажатия 48.
- Один экран — одна мысль. Не больше 5 кусков на первом экране.
- Аватар 88, белое поле вокруг аватара 8, значок состояния на аватаре — круг 28 с иконкой 20.
- Фоновая иллюстрация окна входа: ширина 320, прозрачность 0.06.
- Притушенный кадр рабочего стола под окном входа: слой `--ink` с прозрачностью 0.48, размытие кадра 8. Это затемнение картинки, не стеклянная панель.

## Переключатель срока

- Одна строка, три равных сегмента, как сегментированный контрол Apple.
- Дорожка `--canvas`, радиус 12, внутренний отступ 4. Лежит только на `--surface`.
- Выбранный сегмент `--surface`, радиус 8, одна тень, текст вес 600 `--ink`. Невыбранные — вес 400 `--muted`.
- Скидка — второй строкой в сегменте, Caption, только если пришла с сервера.
- Переезд выбранного сегмента — `transform`, 180 мс.
- Это один компонент на всё приложение: главная и подписка показывают одно и то же значение.

## Компактное окно

- Карточка `--surface` по центру, радиус 20, одна тень, поля 20, ширина экрана минус поля 20.
- Под окном слой `--ink` с прозрачностью 0.32.
- Заголовок Title, 4–6 строк «что откроется», одна акцентная кнопка. Без прокрутки.
- Закрытие: крестик 24 в зоне 48 и системное «назад».
- Появление: прозрачность 0→1 и подъём на 12, 260 мс.

## Знания

- Карточка курса: плитка иконки 44 на `--canvas`, радиус контрола 12; название Body 600, «что на выходе» Body `--ink-soft`, уроки и пройденное Caption `--muted`.
- Доступ на карточке — только знак: замок `--muted` без подписки, галочка `--success` с подпиской. Плашек и слова «Pro» на карточках нет.
- Метка урока: круг 28 на `--canvas`; номер Caption `--muted` или галочка `--success`, если урок пройден.
- Код в уроке: блок `--canvas`, радиус 12, поля 12 по горизонтали и 12 по вертикали, шрифт Code. Подсветка одним цветом `--accent`, остальное `--ink`.
- Поле ответа — тот же блок кода, курсор `--accent`.
- Варианты ответа: строки `--canvas`, радиус 12, высота от 48; выбранный — вес 600 и галочка `--ink`.
- Предпросмотр вёрстки: высота 240, радиус 12.
- Результат: «Верно» — `--success` с галочкой; «Пока не совпало» — `--ink` без красного, ниже «У тебя вышло» и «Ожидалось» блоками кода.
- Прогресс — только числом «пройдено N из M». Полос прогресса в «Знаниях» нет.

## Иконки

- Только lucide, штрих 1.75, размер 20 или 24. Никаких эмодзи вместо иконок.
- Иконка дистрибутива — реальный логотип дистрибутива, не абстрактная «шестерёнка».

## Движение

- Длительности 180 / 260 / 420 мс. Кривые: `cubic-bezier(.2,.8,.2,1)`.
- Анимируется только `transform` и `opacity`. Никаких `transition: all`.
- Каждая анимация имеет `prefers-reduced-motion: reduce`.
- Никаких «пульсирующих скелетов» и бесконечных спиннеров. Прогресс — реальный.
- Появление полноэкранного окна: прозрачность 0→1 и подъём на 12, 260 мс.

## Запрещено

- eyebrow-надписи над заголовками, капслок-лейблы, letter-spacing на мелком тексте
- карточка в карточке
- выдуманные цифры, отзывы, логотипы партнёров
- «нарисованное окно ОС» вместо живого десктопа
- больше одного акцента и больше одной тени на экран

## Экраны

1. **Главная** — витрина: кнопка подписки сверху (или строка с датой окончания), переключатель срока, «что внутри» из живых данных, недоступное одной строкой. Управления системой нет.
2. **Каталог** — единственное место про системы: у каждой размер, сборка, состояние и кнопки «Запустить», «Сменить», «Переустановить», «Остановить».
2a. **Знания** — разделы карточками; без Pro все с замком и при входе один раз компактное окно.
3. **Установка** — реальный прогресс: загрузка и распаковка одним потоком.
4. **Переход в систему** — полноэкранный запуск, проверка подписки, без фейковых этапов.
5. **Десктоп** — живое окно системы, панель, кнопка «Стоп».
6. **Подписка** — Free / Pro / Lifetime, пробный период, требования VK ID.
7. **Вход** — полноэкранное окно поверх приложения: аватар с замком или галочкой, живое состояние системы, одна кнопка «Продолжить с VK ID» (пилюля, поверхность `--surface`, одна тень).

## Тексты

- Коротко, по делу, без восклицаний и без «Давайте».
- Никаких обещаний того, чего нет: Docker, Windows, игры, GPU по умолчанию.
- Цифры только реальные, снятые с работающего устройства.
