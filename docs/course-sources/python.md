## Конспект по темам

- **Ввод и вывод.** `print()` по умолчанию ставит перевод строки (`end="\n"`), несколько аргументов разделяет пробелом (`sep=" "`). `input()` всегда возвращает строку; для чисел нужен `int()`/`float()`. f-строки: `f"{name} {x:.2f}"`.
- **Типы.** `int`, `float`, `str`, `bool`, `None`; `type()`; динамическая типизация — тип у значения, не у имени. `//` — целочисленное деление, `%` — остаток, `**` — степень.
- **Условия.** `if / elif / else`, блок задаётся отступом в 4 пробела. Сравнения цепочкой: `0 < x < 10`. `and`, `or`, `not`.
- **Циклы.** `while` — пока условие истинно; `for x in последовательность`; `range(start, stop, step)` не включает `stop`. `break`, `continue`, `else` у цикла.
- **Списки.** изменяемые, индексы с нуля, отрицательные с конца, срезы `a[1:3]`; `append`, `insert`, `remove`, `pop`, `sort`, `sorted`, `len`, `sum`, `min`, `max`; генераторы списков `[x*x for x in a if x > 0]`.
- **Словари.** пары ключ-значение, ключи уникальны; `d[k]`, `d.get(k, default)`, `items()`, `keys()`, `values()`; подсчёт частот через `get(k, 0) + 1`.
- **Функции.** `def`, параметры по умолчанию, именованные аргументы, `return` (без него — `None`), область видимости: локальные имена не видны снаружи.
- **Файлы.** `open(path, mode, encoding=...)`, режимы `r`, `w` (перезапись), `a` (дозапись); `with` закрывает файл сам; `write` пишет только строки; чтение `read()`, `readlines()`, перебор строк файла в `for`.
- **Ошибки.** синтаксические и ошибки выполнения (исключения): `ValueError`, `ZeroDivisionError`, `KeyError`, `FileNotFoundError`. `try / except Тип / else / finally`, `raise`.
- **Модули.** файл `.py` = модуль; `import math`, `from math import sqrt`, `import x as y`; поиск модулей начинается с каталога запускаемого скрипта; `if __name__ == "__main__":`.
- **Классы.** `class`, `__init__`, `self`, атрибуты объекта, методы, `__str__` для строкового представления, наследование `class B(A)` и `super()`.

## Карта уроков

1. Модуль «Начало» (открыт без Pro): вывод и f-строки · ввод и числа · типы и операции.
2. Условия и циклы: `if/elif/else` · `while` · `for` и `range`.
3. Коллекции: списки · словари.
4. Функции: определение и возврат.
5. Файлы и ошибки: чтение и запись файла · `try/except`.
6. Модули и классы: `import` стандартных модулей · классы.
7. Своя программа: учёт расходов из ввода.

Все задачи проверяются запуском `python3` в гостевой системе, сверка по выводу.
