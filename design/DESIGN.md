# Palma — DESIGN.md

Закрытая система. Любой экран собирается только из этих значений.
Ссылка: Apple (oh-my-design catalog), светлая тема, без градиентов и без рамок.

## Основа

- Продукт: Palmа — рабочий Linux-десктоп на телефоне, без Docker и без root.
- Тон: спокойный, дорогой, немногословный. Интерфейс уходит, содержимое остаётся.
- Светлая тема. Тёмная — отдельная сборка, не инверсия.

## Цвета (только через токены)

```
--canvas:      #f5f5f7
--surface:     #ffffff
--surface-alt: #fafafa
--ink:         #1d1d1f
--ink-soft:    #515154
--muted:       #6e6e73
--accent:      #0071e3
--accent-press:#0062c4
--accent-tint: #eaf2fd
--success:     #1d8a4e
--warning:     #b25000
--hairline:    #d2d2d7
--danger:      #d70015
```

Правила:
- Акцент один. Он только на главном действии экрана и на ссылках. Больше нигде.
- Рамок нет. Границу даёт разница поверхностей и тень, не линия.
- Никаких градиентов, никакого стекла, никаких цветных плашек под текстом.
- Красный (`--danger`) — только для удаления и ошибок, и только словом, не заливкой.
- Дорожка полосы прогресса — `--hairline`, заполнение — `--accent`.

## Шрифт

- Гарнитура: Inter (переменная), fallback — системная. Заголовки вес 600, текст 400.
- Display: 32 / 36, tracking −0.02em
- Title: 20 / 26, tracking −0.01em
- Body: 15 / 22
- Caption: 12 / 16
- Максимум четыре размера на экран. Больше — уже не этот продукт.

## Сетка и форма

- Базовая единица 8. Поля страницы 20. Между блоками 24, внутри карточки 20.
- Радиусы: карточка 20, контрол 12, пилюля 999.
- Тень: `0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.06)`. Одна на карточку.
- Высота кнопки 56, минимальная зона нажатия 48.
- Один экран — одна мысль. Не больше 5 кусков на первом экране.

## Иконки

- Только lucide, штрих 1.75, размер 20 или 24. Никаких эмодзи вместо иконок.
- Иконка дистрибутива — реальный логотип дистрибутива, не абстрактная «шестерёнка».

## Движение

- Длительности 180 / 260 / 420 мс. Кривые: `cubic-bezier(.2,.8,.2,1)`.
- Анимируется только `transform` и `opacity`. Никаких `transition: all`.
- Каждая анимация имеет `prefers-reduced-motion: reduce`.
- Никаких «пульсирующих скелетов» и бесконечных спиннеров. Прогресс — реальный.

## Запрещено

- eyebrow-надписи над заголовками, капслок-лейблы, letter-spacing на мелком тексте
- карточка в карточке
- выдуманные цифры, отзывы, логотипы партнёров
- «нарисованное окно ОС» вместо живого десктопа
- больше одного акцента и больше одной тени на экран

## Экраны

1. **Главная** — что запущено, одно действие, состояние подписки строкой.
2. **Каталог** — три дистрибутива, у каждого размер, время установки и что внутри.
3. **Установка** — реальный прогресс: загрузка и распаковка одним потоком.
4. **Переход в систему** — полноэкранный запуск, проверка подписки, без фейковых этапов.
5. **Десктоп** — живое окно системы, панель, кнопка «Стоп».
6. **Подписка** — Free / Pro / Lifetime, пробный период, требования VK ID.

## Тексты

- Коротко, по делу, без восклицаний и без «Давайте».
- Никаких обещаний того, чего нет: Docker, Windows, игры, GPU по умолчанию.
- Цифры только реальные, снятые с работающего устройства.
